# Лабораторная работа № 9

## Интеграция автоматизированных тестов в CI/CD

Для автоматической проверки используется API-тестирование из лабораторной работы № 5: тесты `pytest` отправляют GET, POST и PUT запросы к JSONPlaceholder и проверяют ответы.

### Локальный запуск

Требуются Python 3 и подключение к интернету. В корне проекта выполните:

```powershell
python -m pip install -r requirements.txt
python -m pytest -v
```

Ожидаемый результат — `3 passed`.

### GitHub Actions

Workflow находится в `.github/workflows/run-tests.yml`. Он запускается при каждом push, pull request, а также вручную через вкладку **Actions**. Workflow использует Ubuntu, устанавливает Python 3.12 и зависимости из `requirements.txt`, затем запускает `pytest`.

Чтобы проверить его на GitHub:

1. Создайте публичный репозиторий на GitHub.
2. Загрузите в него содержимое этой папки, включая скрытую папку `.github`.
3. Сделайте push в репозиторий.
4. Откройте вкладку **Actions** и выберите запуск **Run API tests**. Успешный запуск отмечается зелёной галочкой.

Тесты обращаются к общедоступному JSONPlaceholder, поэтому для их прохождения runner должен иметь доступ к интернету.
